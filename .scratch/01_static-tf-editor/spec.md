# Static TF 編輯面板、URDF 匯出與 3D 預覽

Status: ready-for-agent

日期：2026-10-28

## Problem Statement

使用者需要在現有 ARC TF Viewer 中調整一組 parent／child frame 的相對姿態，立即觀察 TF 結果，調校完成後把相同設定移入 URDF 或 xacro。目前程式只有 TF 樹檢視與轉換查詢，缺少互動發布、數值調整與可複製的 fixed joint 輸出。

使用情境包含建立新的 child frame，以及把兩個斷開的 TF 分支連接起來。使用者也需要在不依賴機器人模型的情況下，透過兩組 RGB 三軸理解姿態關係，且預覽相機不能突然跳動。

## Solution

主視窗提供 Static TF 按鈕，開啟可與主視窗同時操作的獨立面板。一次編輯一組 parent／child，以數值框和可長按的加減按鈕調整 XYZ／RPY，支援顯示單位與共用步長切換。

Enable 開啟時立即發布 static TF；後續每次有效數值變更都立即更新。面板同時提供符合 URDF 慣例的 fixed joint XML 預覽與複製功能，以及右上角的兩組 RGB 三軸 3D 預覽。相機支援平滑自動環繞、取景、手動旋轉與縮放。

## User Stories

1. 身為 TF 調校使用者，我希望從主視窗開啟 Static TF 面板，以便在既有工具內完成調校。
2. 身為 TF 調校使用者，我希望面板開啟時仍能操作主視窗，以便同時檢查 TF 樹與轉換查詢。
3. 身為 TF 調校使用者，我希望一次專注調整一組 parent／child，以便清楚掌握正在發布的關係。
4. 身為 TF 調校使用者，我希望搜尋或輸入既有 parent frame，以便快速找到連接起點。
5. 身為 TF 調校使用者，我希望輸入新的 parent frame，以便建立新的根節點或連接現有分支。
6. 身為 TF 調校使用者，我希望自訂新的 child frame 名稱，以便測試新的安裝位置或參考座標。
7. 身為 TF 調校使用者，我希望選另一個斷開分支的根 frame 作為 child，以便連接兩棵 TF 樹。
8. 身為 TF 調校使用者，我希望系統拒絕已有其他 parent 的 child、自我連接及迴圈，以免破壞 TF 拓樸。
9. 身為 TF 調校使用者，我希望自己建立的 child 可持續更新，以免第一次發布後被誤判為既有名稱衝突。
10. 身為 TF 調校使用者，我希望 Enable 期間鎖住 parent／child，以免調整姿態時意外換了連接對象。
11. 身為 TF 調校使用者，我希望直接輸入 XYZ／RPY，以便精確設定姿態。
12. 身為 TF 調校使用者，我希望每個數值框兩側都有減號和加號，以便逐步微調。
13. 身為 TF 調校使用者，我希望長按加減按鈕能連續調整、放開即停止，以便快速移動數值。
14. 身為 TF 調校使用者，我希望用共用 radio button 選擇 10、1、0.1 或 0.01 的步長，以便切換粗調與細調。
15. 身為 TF 調校使用者，我希望步長依目前顯示單位套用，以便直接理解每次操作的變化量。
16. 身為 TF 調校使用者，我希望 XYZ 預設使用公尺，並能循環切換 m、cm、mm，以便符合不同尺寸的調校工作。
17. 身為 TF 調校使用者，我希望 RPY 預設使用 rad，並能切換 deg，以便用熟悉的角度單位操作。
18. 身為 TF 調校使用者，我希望切換單位只換算顯示，以免位置或角度因此改變。
19. 身為 TF 調校使用者，我希望 XYZ 不受先前討論的 ±1 m 或 ±10 m 限制，以便設定較遠的分支距離。
20. 身為 TF 調校使用者，我希望啟用時立刻發布目前有效設定，以便立即開始測試。
21. 身為 TF 調校使用者，我希望啟用後每次有效編輯都立即發布，以便感受到連續、即時的調整。
22. 身為 TF 調校使用者，我希望停用時可以先修改設定而不發布，以便準備下一次測試。
23. 身為 TF 調校使用者，我希望清楚知道停用不會撤回已發布的 static TF，以免誤認分支已斷開。
24. 身為 TF 調校使用者，我希望關閉面板只隱藏並保留 Enable 與數值，以便不因誤關面板中斷操作。
25. 身為 TF 調校使用者，我希望重新開啟面板時回到同一組設定，以便繼續調校。
26. 身為 TF 調校使用者，我希望重新啟動程式後恢復先前設定，但 Enable 保持關閉，以便確認後才重新發布。
27. 身為 URDF 編輯者，我希望 XYZ／RPY 與 URDF origin 意義一致，以便把測試結果直接用於機器人描述。
28. 身為 URDF 編輯者，我希望看到即時 fixed joint XML 預覽，以便確認將要複製的內容。
29. 身為 URDF 編輯者，我希望輸出固定使用 m／rad 並顯示小數點後 4 位，以免把顯示用的 mm 或 deg 誤貼入 URDF。
30. 身為 URDF 編輯者，我希望 joint 名稱有自動預設值且可修改，以便配合既有命名方式。
31. 身為 URDF 編輯者，我希望選擇是否包含 child link 宣告，以便新增 link 時方便、連接既有 link 時避免重複宣告。
32. 身為 URDF 編輯者，我希望一鍵複製 XML 片段，以便貼進 URDF 或 xacro。
33. 身為 TF 調校使用者，我希望面板右上角顯示 parent／child 的 RGB 三軸及名稱，以便辨識兩者的相對位置與旋轉。
34. 身為 TF 調校使用者，我希望未啟用發布時仍可預覽，以便先檢查草稿姿態。
35. 身為 TF 調校使用者，我希望預覽預設緩慢環繞，以便從不同方向理解兩組三軸的關係。
36. 身為 TF 調校使用者，我希望自動取景能容納兩個 frame，以便距離變大後仍看得到兩者。
37. 身為 TF 調校使用者，我希望用滑鼠旋轉和滾輪縮放，以便檢查特定角度或細節。
38. 身為 TF 調校使用者，我希望手動操作後暫停自動控制，以免相機與我的操作互相干擾。
39. 身為 TF 調校使用者，我希望從目前視角恢復自動環繞，以免切換模式時跳回其他位置。
40. 身為 TF 調校使用者，我希望能重設視角並恢復自動取景與環繞，以便快速找回兩個 frame。
41. 身為 TF 調校使用者，我希望所有相機變化都平滑進行，以免旋轉、縮放或重設造成突然跳動。
42. 身為 TF 調校使用者，我希望三軸姿態立即反映數值而不做姿態緩動，以便畫面忠實顯示當下設定的 TF。
43. 身為 TF 調校使用者，我希望一鍵將 XYZ／RPY 歸零，以便快速重置姿態。

## Implementation Decisions

- 沿用既有 C++17、Qt5 Widgets 與 ROS 2 應用。主視窗目前持有 ROS node、TF buffer 與 listener，並以 Qt timer 處理 ROS 及 TF 查詢。新功能應整合現有 frame 資訊來源，保留既有樹狀檢視與查詢行為。
- 增加一個獨立、非模態、可重複開啟的 Static TF 面板。空間允許時首次開啟於主視窗旁，可將主視窗切到面板前方；關閉主視窗時一併隱藏面板。主視窗按鈕開啟或帶出同一個面板；關閉面板僅隱藏，不重置數值或 Enable，也不銷毀正在使用的發布功能。
- 面板只編輯一組連接。Parent 使用可搜尋／輸入的 frame 選擇器；可選擇既有 frame，也可輸入新名稱作為根節點。
- Child 支援新名稱，以及另一個斷開分支的根 frame。驗證不得與 parent 相同，不得奪取已有其他 parent 的 frame，也不得形成迴圈。本功能已成功建立的連接允許再次更新，不能因其出現在 TF buffer 中就拒絕操作。
- 根 frame 的識別須包含只出現在 parent 端的 frame。拓樸檢查不能只比對名稱，必須檢查祖先關係與分支連通性。
- Enable 開啟前驗證 frame 與數值；啟用期間鎖住 parent／child 選擇，關閉後才能修改連接對象。
- 使用 static TF broadcaster 發布到 `/tf_static`。啟用時發布一次，其後每次有效數值改變立即發布；不等待失去焦點、放開按鈕或低頻輪詢。不因沒有修改而要求持續重發。
- Enable 關閉只停止後續更新，不承諾刪除其他節點已接收的 static TF。面板應明確提示此行為。更換 child 後舊 frame 也可能繼續存在；「一組」指本面板目前編輯的連接，不代表能清除歷史發布資料。
- 六個軸各自使用 QDoubleSpinBox，顯示小數點後 4 位，左右安排減號與加號；不使用滑桿或自訂標籤拖曳。單擊增減一步，長按連續增減，放開停止。保留原生鍵盤輸入；數值框自身的步進操作與外部加減按鈕共用目前步長。
- 提供 Clear pose 按鈕，一次將 XYZ／RPY 歸零，保留 frame、單位與步長；Enable 時立即發布歸零後的姿態。
- 一組 radio button 控制全部六軸步長，選項為 ×10、×1、×0.1、×0.01，預設 ×0.01。選項直接代表目前顯示單位的增減量，例如 ×0.1 在 mm 顯示時為 0.1 mm，在 deg 顯示時為 0.1 deg。
- XYZ 共用單位按鈕，預設 m，循環 m → cm → mm → m；RPY 共用單位按鈕，預設 rad，切換 rad ↔ deg。切換時保持實際姿態不變，不能因顯示精度或來回換算累積改變 TF。
- XYZ 不設 ±1 m 或 ±10 m 的產品限制；可表示範圍仍受有限浮點數及元件能力限制。空白、編輯中的不完整輸入、非有限值不可發布為 TF。
- 面板、發布資料、URDF 預覽及 3D 預覽共享同一份姿態意義。XYZ 是 parent 座標系中的 child 原點位置；RPY 使用 URDF 固定軸 X／Y／Z 的 roll／pitch／yaw 慣例。轉換成 ROS 四元數時保持此定義。
- URDF 預覽唯讀並隨有效設定更新，不依賴 Enable。輸出 fixed joint、parent、child 與 origin；數字一律使用 m／rad，採 XML 可解析的數字格式並輸出小數點後 4 位；發布的 TF 保留內部精度。複製按鈕把目前預覽片段放入剪貼簿。
- Joint 名稱可編輯，預設為 `<parent>_to_<child>_joint`。提供「Parent link」及「Child link」切換按鈕，分別控制各自的 link 宣告；新 frame 預設勾選，既有 frame 預設不勾選。是否包含宣告是使用者可覆寫的選擇。
- 預覽輸出可放入既有 URDF 或 xacro 的 robot 內容，不產生整份 robot 文件。輸出須正確處理 XML 屬性字元，避免名稱造成無效 XML。
- 使用 QSettings 保存 parent／child、XYZ／RPY、顯示單位與步長；每次啟動應用都強制 Enable 關閉。恢復的 frame 名稱仍須依目前 TF 環境驗證。
- 面板右上角提供輕量 3D 預覽，只顯示兩組座標軸及 frame 名稱，不載入機器人模型。X 紅、Y 綠、Z 藍，不顯示軸端文字，並在 parent 的 XY 平面顯示格線；兩組軸使用一致的尺度，姿態來自目前編輯值，停用時仍顯示。
- 相機預設開啟自動環繞，約 30 秒一圈，以兩個 frame 的中點為觀看中心，並自動取景使兩組三軸保持可見。兩者重合時也須有可用的觀看距離。
- 滑鼠支援旋轉，滾輪支援縮放。開始手動操作後暫停自動環繞與自動取景，保留手動視角。「自動環繞」從當前相機狀態接續；「重設視角」恢復自動取景及環繞。
- 相機旋轉、縮放、中心追蹤、自動取景、模式切換及重設都使用平滑過渡，不能瞬間跳到新相機狀態。姿態改變時保持觀看方向的連續性；自動取景需要調整中心或距離時逐步追蹤。
- 三軸的位置與方向直接更新到有效設定值，不做姿態插值；相機平滑不能延遲 TF 發布或 URDF 更新。
- 以完整面板作為主要行為測試邊界。內部可分離編輯狀態、ROS 發布、持久設定與繪圖責任，但本規格不預先鎖定類別拆分或 3D 繪圖技術。

## Testing Decisions

- 已與使用者確認：以完整 Static TF 面板的對外行為作為主要測試入口，不針對私有方法、內部容器、類別結構或特定繪圖後端撰寫鏡像測試。
- 現有專案只有套件層的 lint 測試相依宣告，未發現功能測試或已設定的測試 target。沒有可直接沿用的同類面板測試案例；應在既有 Qt／ROS 環境建立最少必要的整合測試設施。
- 測試透過欄位與按鈕操作面板，使用隔離的 ROS 測試圖提供已知 frame，從獨立訂閱者／TF listener 觀察輸出。設定保存使用隔離的使用者設定目錄，避免污染真實設定。
- 驗證新 parent 搭配新 child 或另一分支根 frame 可啟用；自我連接、已有其他 parent 的 child 及形成迴圈的選擇均被拒絕。包含根節點只出現在 parent 端的案例，以及首次發布後修改同一連接的案例。
- 驗證 Enable 首次發布、啟用後輸入與加減即時更新、停用後無新姿態發布、啟用時 frame 欄位鎖定。以實際收到的 transform 判定結果，不只檢查函式被呼叫。
- 驗證 Clear pose 讓六軸歸零、保留 frame／單位／步長，並在 Enable 時發布歸零姿態。
- 驗證長按連續步進、放開停止，以及全部步長在 m／cm／mm／rad／deg 下的實際量。比較物理姿態，確保來回切換單位不改變結果。
- 驗證超過 ±10 m 的有效數值可使用，且不完整或非有限輸入不會流入發布結果。
- 驗證非零平移、單軸旋轉及混合 RPY 的結果。以獨立的 URDF 解析／轉換結果與 ROS transform 比較，避免只用同一套被測轉換函式產生期待值；比較四元數時接受正負號等價。
- 驗證預覽為可解析的 fixed joint XML，parent／child、joint 名稱、origin 數值及可選 child 宣告正確；切換顯示單位後仍輸出 m／rad。驗證剪貼簿內容與預覽一致，且停用時仍隨編輯更新。
- 驗證隱藏／重新開啟面板保留狀態且不建立第二個編輯實例；應用重啟後恢復已約定設定，但不會自動發布。
- 3D 行為驗收包括 RGB 軸方向、名稱、停用時預覽、姿態立即更新、約 30 秒環繞、兩 frame 重合／遠離時的取景、手動操作暫停自動控制，以及兩個相機控制按鈕的行為。
- 相機平滑度以實際畫面操作驗收為主：連續改值、長按、旋轉、滾輪縮放、重設及恢復環繞時不得突然跳位；同時確認平滑只作用於相機，三軸與發布值不被延遲。不要用脆弱的逐像素快照替代動態驗收。
- 驗證現有 TF 樹刷新與轉換查詢仍可在面板開啟時操作。完成 Qt／ROS 編譯與上述必要驗證後，記錄測試環境及未能驗證的項目，不宣稱固定毫秒級延遲或跨機器完全相同的動畫速度。

## Out of Scope

- 同時管理多組可編輯 TF、批次發布或 TF 清單管理。
- Dynamic TF 發布模式，以及從所有遠端 listener 撤回／刪除 static TF。
- 覆寫其他發布來源已擁有的 child，或建立有迴圈的 TF 圖。
- QSlider、自訂數字／標籤拖曳、使用滑鼠直接拖動 3D 三軸修改姿態。
- 載入 URDF mesh、顯示完整機器人、碰撞檢查、物理模擬或 RViz 等級的場景編輯。
- Revolute／prismatic 等非 fixed joint、joint limit 或動態運動規劃。
- 自動修改使用者的 URDF／xacro 檔案、生成 xacro 巨集或輸出完整 robot 文件。
- 重啟後自動 Enable，以及同步多台電腦的使用者設定。
- 此規格的發布不包含功能實作、實作票單拆分或 git commit。

## Further Notes

- 本規格由本次 grilling 討論整理，測試邊界已獲使用者確認，依本地 tracker 慣例標記為 ready-for-agent。
- 已確認的持久設定位置為 `~/.config/arc_tf_viewer/settings.ini`，不是暫存目錄。
- 「臨時」指互動調校用途，不代表 static TF 具有到期時間。停用、隱藏面板或關閉應用均不能保證遠端快取中的 frame 消失；更換連接對象時也須保留這個限制的說明。
- TF frame 名稱與 URDF link 名稱未必在所有外部系統中相同。預覽按所選名稱輸出；使用者負責確認貼入的 robot 描述確實具有相應 parent／既有 child，工具不讀取或修改外部模型來推測映射。
- 未約定的細節包含長按起始延遲／重複間隔、相機緩動時間常數及具體繪圖後端。實作時依上述行為與驗收要求選擇合理值，不把這些當作已由使用者指定的數字。
- 參考依據：[ROS 2 static broadcaster](https://github.com/ros2/geometry2/blob/rolling/tf2_ros/src/static_transform_broadcaster.cpp)、[static cache](https://github.com/ros2/geometry2/blob/rolling/tf2/src/static_cache.cpp)、[URDF joint 規格鏡像](https://mirror.umd.edu/roswiki/urdf%282f%29XML%282f%29joint.html)。實作時應核對本機 ROS 發行版的對應 API。
